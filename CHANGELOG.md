# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- Версионированный JSON-экспорт и восстановление профиля, контента и прогресса.
- Атомарный импорт контент-паков с навыками, повторениями и квестами, проверкой дублей и конфликтов.
- Сгруппированные события XP с названием источника, датой и разбивкой по навыку и характеристике.
- Выбор иконки и цвета навыка с отображением в списке и деталях.
- Мобильные карточки достижений с описанием, статусом и датой получения.
- Полная форма квеста: характеристика, дедлайн, ручное/автоматическое завершение, обязательные и дополнительные шаги.
- Редактирование, сортировка шагов, архивирование и восстановление квестов.
- Связь шага квеста с задачей дня: выполнение задачи закрывает шаг и может автоматически завершить квест.
- Отображение характеристики, дедлайна и прогресса обязательных шагов в списке и деталях квеста.
- Навигация по дням на экране «Сегодня» (стрелки, «к сегодня»); повторяющиеся задачи материализуются только для сегодня.
- Редактирование и удаление/отмена задачи (`PATCH`/`DELETE /api/tasks/:id`); отменённые скрыты, задачи из шаблона отменяются со статусом `cancelled`.
- Выбор области при редактировании задачи из шаблона: «только эту» / «эту и будущие».
- Полное управление шаблонами в профиле: редактирование, пауза/возобновление, расписание и архив.
- Длительность задачи в форме и карточке, описание в карточке, живой предпросмотр итогового XP.

### Changed

- XP за период и график включают задачи и награды квестов; распределение характеристик учитывает выбранный период.
- `GET /api/xp-transactions` возвращает события вместо отдельных технических строк журнала.
- Характеристику навыка можно изменить только до первой записи XP; отмена начисления не снимает ограничение.
- Перед отменой выполнения показываются последствия для XP, серии и уже открытых достижений.
- Единый диапазон базового XP (`BASE_XP` 5–250) для задач и шаблонов в API и UI.

### Fixed

- Пул соединений PostgreSQL переиспользуется при hot reload в режиме разработки.
- Завершение квеста требует выполнения всех обязательных шагов; шаги завершённого/архивного квеста заморожены.
- Квест требует минимум один шаг.
- Серии стали schedule-aware (учитывают дни недели) и обнуляются относительно сегодня при пропуске.
- Прогресс за «всё время»: корректный итоговый XP и ограниченное окно графика.
- Запрет смены характеристики навыка после начисления XP; архивирование навыка каскадно архивирует его шаблоны.
- Валидация реальной календарной даты (`2026-02-31` больше не проходит) и связная валидация PATCH шаблона.
- Readiness-эндпоинт `/api/ready` с проверкой БД (отделён от liveness `/api/health`).
- Обязательная проверка секретов окружения в production.

### Added

- Security headers (`X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, HSTS в prod).
- Отдельный шаг миграций в деплое (`migrator`-стейдж + one-off `migrate`-сервис) — без гонок при старте.
- Скрипты бэкапа и восстановления PostgreSQL (`scripts/backup.sh`, `scripts/restore.sh`) с ротацией 7/4/6.
- E2E-тесты (Playwright) основных сценариев через dev-обход.
- Экран навыков (группировка по характеристикам, уровни/прогресс) и деталь навыка с историей XP и связанными действиями.
- Создание, редактирование и архивирование навыков.
- Экран «Прогресс»: статистика за 7/30 дней и всё время, график XP по дням (recharts), распределение по характеристикам, последние начисления.
- Экран «Профиль»: характеристики, достижения, темы (next-themes), часовой пояс, управление шаблонами, выход.
- Экспорт всех данных пользователя в JSON.
- API: `GET`/`PATCH /api/skills/:id`, `DELETE`, `GET`/`PATCH /api/profile`, `GET /api/progress`, `GET /api/xp-transactions`, `GET /api/export`.
- Полностью включена нижняя навигация (Навыки, Прогресс, Профиль).
- Квесты: CRUD, шаги с прогрессом, транзакционное завершение с XP-наградой, авто-завершение по шагам.
- Экраны «Квесты» (табы Активные/Завершённые/Архив) и деталей квеста с подтверждением завершения.
- Стартовый набор из 8 достижений, синхронная проверка после действий и показ в toast.
- Нижняя навигация приложения (Сегодня, Квесты активны).
- API: квесты (`GET`/`POST`/`PATCH`/`complete`), `POST /api/quest-steps/:id/toggle`, `GET /api/achievements`.
- Шаблоны повторяющихся задач (ежедневно / выбранные дни недели) и их CRUD.
- Ленивое создание задач дня из активных шаблонов при открытии «Сегодня» — без cron и дублей.
- Серии выполнения по шаблонам с индикатором 🔥 и показом в toast.
- Отмена выполнения (revert): компенсирующие XP-транзакции, откат кэшей, пересчёт серии.
- Recurrence в форме добавления и кнопка «Отменить» на выполненных задачах.
- API: `POST`/`GET /api/task-templates`, `PATCH`/`DELETE /api/task-templates/:id`, `POST /api/tasks/:id/revert`.
- Игровой цикл: характеристики, навыки, разовые задачи, XP-журнал и формула уровней.
- Транзакционное завершение задачи с начислением XP в общий уровень, навык и характеристику; идемпотентный повтор.
- Экран «Сегодня»: уровень и прогресс, XP за день, список задач, добавление действия, toast с результатом начисления.
- API: `POST /api/tasks`, `POST /api/tasks/:id/complete`, `GET`/`POST /api/skills`.
