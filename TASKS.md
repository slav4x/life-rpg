# TASKS — Life RPG

Актуальный план технической очистки после ревью кода. Продуктовые задачи ведутся в `BACKLOG.md`.

## P0 — корректность и изоляция данных

- [ ] Проверять новый `skillId` при редактировании повторения: навык должен принадлежать текущему пользователю и быть активным.
  - [ ] Добавить проверку в application-слой.
  - [ ] Покрыть смену на чужой и архивный навык интеграционными тестами.
  - [ ] По возможности закрепить принадлежность навыка пользователю ограничением на уровне БД.
- [ ] Сделать создание повторения и первой задачи атомарным: выполнять обе операции в одной транзакции.
- [ ] Сделать архивацию навыка и связанных повторений атомарной: выполнять обе операции в одной транзакции.
- [ ] Усилить проверку ссылочной целостности при импорте резервной копии.
  - [ ] Проверять ссылки `userSkills → skills`.
  - [ ] Проверять ссылки `streaks → taskTemplates`.
  - [ ] Проверять `xpTransactions.sourceId` для транзакций, связанных с выполнением задач.
  - [ ] Добавить тесты импорта повреждённых и неполных резервных копий.

## P1 — логика и производительность

- [ ] Добавить пакетную материализацию повторяющихся задач для диапазона дат.
  - [ ] Загружать активные шаблоны один раз.
  - [ ] Создавать недостающие задачи одной пакетной операцией.
  - [ ] Перевести экран «Сегодня» на новый сценарий вместо семи отдельных вызовов.
- [ ] Оптимизировать недельный прогресс: загружать XP за общий диапазон один раз и вычислять текущий, предыдущий и выбранный периоды в памяти.
- [ ] Убрать неиспользуемый запрос просроченных задач из `weeklyQuestSummary`, если эти данные по-прежнему не используются интерфейсом.
- [ ] Исправить перенос сфокусированной задачи на другую дату.
  - [ ] При переносе сбрасывать фокус либо назначать свободную позицию на целевой дате.
  - [ ] Блокировать и проверять позиции фокуса для целевого дня.
- [ ] После появления полноценного онбординга убрать runtime-вызовы `ensureWorkspace` и автоматическое создание `STARTER_SKILLS`.

## P2 — удаление неактуального кода

- [ ] Удалить неиспользуемый `src/components/ui/card.tsx`.
- [ ] Удалить неиспользуемые функции `deleteTask`, `findUserById` и `maxCurrentStreak`.
- [ ] Сделать `listRecentTransactions` внутренней функцией модуля, если внешние вызовы не появятся.
- [ ] Определить политику публичного API.
  - [ ] Если внешний API не планируется — удалить неиспользуемые read-endpoints `/api/achievements`, `/api/xp-transactions`, `/api/progress` и неиспользуемые `GET`-ветки профиля, навыков, квестов и повторений.
  - [ ] Если внешний API нужен — оставить endpoints и добавить контрактные тесты.
- [ ] Добавить в CI проверку неиспользуемых файлов и экспортов через `knip` или аналогичный инструмент.

- [ ] Разделить `profile-settings.tsx` на настройки интерфейса и часового пояса, импорт/экспорт данных и управление сессией.
- [ ] Вынести общие поля задачи/повторения и UI настройки расписания из drawer-компонентов.
