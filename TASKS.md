### Требует ручной проверки

- `docker compose build` / `docker build` и ответ `/api/health` в контейнере.
- `npm run test:e2e` — предварительно `npx playwright install`.
- Локальный Node 23 вне поддерживаемого диапазона Next 16 (нужен `>=20.19`/`22.13+`/`24`).
  Dev/сборка работают, но рекомендуется LTS; Docker уже использует `node:24-alpine`.
