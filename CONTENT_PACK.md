# Формат контент-пака

Контент-пак — JSON-файл для атомарного импорта навыков, разовых задач, повторяющихся
действий и квестов. Текущая версия — `2`; файлы версии `1` продолжают поддерживаться.

## Пример v2

```json
{
  "format": "life-rpg-content-pack",
  "formatVersion": 2,
  "name": "Чтение и фокус",
  "skills": [
    {
      "key": "reading",
      "name": "Чтение",
      "attributeCode": "mind",
      "description": "Осмысленное чтение книг",
      "icon": "📚",
      "color": "#6366F1"
    }
  ],
  "tasks": [
    {
      "title": "Выбрать следующую книгу",
      "skillKey": "reading",
      "baseXp": 20,
      "difficulty": "easy",
      "estimatedMinutes": 30,
      "scheduledInDays": 1
    }
  ],
  "taskTemplates": [
    {
      "title": "Читать 20 минут",
      "description": "Без уведомлений и параллельных дел",
      "skillKey": "reading",
      "baseXp": 20,
      "difficulty": "easy",
      "recurrenceType": "weekdays",
      "weekdays": [1, 2, 3, 4, 5],
      "estimatedMinutes": 20,
      "startsInDays": 0,
      "endsInDays": 90
    }
  ],
  "quests": [
    {
      "title": "Прочитать одну книгу",
      "description": "Выбрать, прочитать и законспектировать",
      "type": "side",
      "attributeCode": "mind",
      "rewardXp": 150,
      "dueInDays": 30,
      "manualCompletion": true,
      "steps": [
        { "title": "Выбрать книгу", "isRequired": true },
        { "title": "Дочитать", "isRequired": true },
        { "title": "Сделать конспект", "isRequired": false }
      ]
    }
  ]
}
```

## Поля и ограничения

- `attributeCode`: `body`, `mind`, `resources`, `social`, `discipline`, `creation`;
- `difficulty`: `easy`, `normal`, `hard`, `epic`;
- `recurrenceType`: `daily` или `weekdays`; для `weekdays` обязательны дни `1–7`;
- `type`: `main`, `side`, `long_term`;
- `baseXp`: `5–250`, `rewardXp`: `0–10000`;
- `estimatedMinutes`: необязательная длительность задачи или повторения, `1–1440`;
- `scheduledInDays`: дата разовой задачи относительно даты предпросмотра, `0–3650`;
- `startsInDays` и `endsInDays`: границы повторения относительно даты предпросмотра,
  `0–3650`; окончание не может быть раньше начала;
- `dueInDays`: дедлайн квеста относительно даты предпросмотра, `0–3650`;
- `icon`: `✨`, `💪`, `🧠`, `💼`, `🤝`, `🎨`, `⚡`, `📚`;
- `color`: `#6366F1`, `#0EA5E9`, `#14B8A6`, `#22C55E`, `#F59E0B`,
  `#F97316`, `#EC4899`, `#8B5CF6`.

Все относительные даты вычисляются от локальной даты пользователя. Предпросмотр возвращает
`anchorDate`; подтверждение использует ту же дату, поэтому результат не сдвинется, если между
предпросмотром и импортом наступит новый календарный день.

`key` связывает задачи и шаблоны с навыками внутри одного файла и не сохраняется в БД.

## Предпросмотр и выбор разделов

Загрузка файла не меняет данные. Сначала интерфейс показывает по каждому разделу количество
записей, которые будут созданы, пропущены как идентичные или отклонены. Можно отдельно выбрать:

- навыки;
- разовые задачи;
- повторения;
- квесты.

Зависимости проверяются повторно после каждого изменения выбора. Разовую задачу или повторение
нельзя импортировать без связанного навыка, если идентичного активного навыка ещё нет в профиле.
При любом конфликте в выбранных разделах подтверждение блокируется. После подтверждения все
выбранные записи создаются одной транзакцией; частичного результата не остаётся.

## Совместимость версий

Версия `1` остаётся доступной для импорта:

- в ней нет массива `tasks`;
- повторения начинаются в локальную дату импорта;
- квест может использовать абсолютное поле `dueDate` в формате `YYYY-MM-DD`;
- остальные поля и правила дубликатов сохраняют прежнее поведение.

Для миграции v1 → v2:

1. Изменить `formatVersion` на `2`.
2. Добавить `tasks` — пустой массив или список разовых задач.
3. Заменить абсолютный `dueDate` на число дней `dueInDays`.
4. При необходимости добавить `scheduledInDays`, `startsInDays` и `endsInDays`.

Неизвестные версии отклоняются. Повторный импорт идентичного контента с тем же `anchorDate`
безопасен: записи пропускаются. Если совпадает название и дата, но отличаются параметры,
предпросмотр показывает конфликт.

Полный пользовательский экспорт имеет другой маркер — `life-rpg-export`. Его импорт
восстанавливает профиль, контент и прогресс с заменой текущих данных после подтверждения.
